# open-mechanical

Ansys Mechanical の代わりに使える、**無料の静的構造解析ソフト**（Python デスクトップアプリ）です。
操作の流れは Ansys と同じく **形状 → メッシュ → 材料 → 境界条件 → 解析 → 結果** です。

## できること（v0.1）

| 項目 | 内容 |
|---|---|
| 解析 | 静的構造解析（3次元・等方弾性）。**接触・大変形・複数ステップ**の非線形にも対応 |
| 接続（接触） | 自動検出＋手動。タイプ: 結合／分離なし／摩擦なし／粗い／摩擦あり（摩擦係数）。定式化: 拡張ラグランジュ／ペナルティ／MPC、法線剛性係数、ピンボール、インターフェース処理（調整して接触／オフセット） |
| 材料 | Ansys Engineering Data 相当: 等方弾性（**温度依存**の E・ν 表）、**直交異方性**（Ex,Ey,Ez, νxy,νyz,νxz, Gxy,Gyz,Gxz）、**異方性**（6×6 剛性）、材料の向き（ボディ属性で回転）、**熱膨張**（等方・直交異方性、参照温度）、**塑性**（ミーゼス: 2直線/多直線 × 等方硬化/移動硬化、**大変形と組み合わせ可**＝Total Lagrangian・グリーンひずみの加法分解） |
| 熱条件 | ［環境］→「熱条件」でボディの温度を指定（物性を温度で評価＋熱ひずみ）。環境温度は「静的構造」の詳細 |
| メッシュ | Ansys 風の設定: 要素次数、要素サイズ／解像度、成長率、曲率の捕捉（法線角度・最小サイズ）、スムージング、品質（要素品質・歪度・アスペクト比）。メッシュ制御: サイズ指定（面・ボディ、ソフト/ハード）、影響球、リファインメント、**スイープ**（分割数・方向） |
| シェル | サーフェス（平板・多角形面・円筒面）＋厚さ → 3節点シェル（DKT 曲げ＋Allman 膜、SHELL181 相当）。辺の選択で支持・力、面に圧力。上面/下面の応力 |
| 節点共有 | Ansys のトポロジ共有と同じ。［モデル］タブ →「パート作成」で選んだボディ同士の界面節点を共有（接触なしで一体として解析）。共有方法は「しない／すべて／パートごと」 |
| 並列計算 | 解析設定 →「使用コア数」。組立・応力計算・反復法ソルバーを並列化。大きなモデルは AMG 前処理付き共役勾配法（相対残差 1e-10 まで＝直接法と同じ解）を自動選択 |
| 解析設定 | Ansys と同じ項目: ステップ数・ステップ終了時間・自動時間ステップ・サブステップ、ソルバータイプ・弱いバネ・大変形、ニュートン・ラフソン・力の収束・ラインサーチ・最大反復、出力制御 |
| 要素 | 2次四面体 Tet10（Ansys の SOLID187 相当・既定）／1次四面体 Tet4 |
| 形状 | **モデリング**（直方体・円柱・パイプ・円錐・球・押し出しを「追加 / 切り取り / 交差」で組み合わせ）、**STEP**、IGES、**STL** |
| 拘束 | 固定支持、強制変位（成分ごとに拘束/自由 → ローラー支持など） |
| 荷重 | 力、圧力、モーメント、重力（加速度） |
| 結果 | 全変形・方向変形、相当応力（ミーゼス）、主応力、応力成分、**安全率**、反力、質量、**接触ツール**（接触状態・接触圧・貫通量・すべり距離・摩擦応力・隙間）、ステップごとの表示時間、収束履歴 |
| メッシュ | 全体サイズ＋**面ごとのサイズ指定**（穴・角などを局所的に細かく） |
| 表示 | コンター（Ansys 風 9 段階）、変形倍率、最大/最小の位置、右クリックで値を確認 |
| 出力 | HTML レポート（印刷→PDF）、VTU（ParaView）、CSV（Excel） |

### 対応していないもの
- **.x_t / .x_b（Parasolid）**：Siemens の独自形式で、無償で読めるライブラリが存在しません。
  CAD から **STEP** で書き出して読み込んでください（CAD の面がそのまま選択できます）。

## そのあと追加した機能と、画面のどこにあるか

上の表は最初の版のものです。その後に入った機能を、使う場所ごとにまとめます。

| 機能 | 場所 | メモ |
|---|---|---|
| 解析の種類: モーダル・固有値座屈・定常/過渡熱・熱応力・調和応答・ランダム振動・応答スペクトル・静電場・圧電・過渡構造（陰解法/陽解法） | ツリー「静的構造」を選び、詳細の「解析の種類」 | 過渡構造（陰解法）は接触・塑性・大変形があると非線形の解き方になる |
| 塑性（等方/移動硬化の 2 直線・多直線、Chaboche）、超弾性（Neo-Hookean・Mooney-Rivlin・Yeoh）、クリープ（Norton）、複合材の強度 | 材料定数の編集の各タブ | Chaboche は「強度・塑性」タブの C・γ の表 |
| 接触: 有限すべり、ガスケット、ボルトねじ | ツリーの接触領域 → 詳細 | 「すべり」は大変形オンで自動的に有限すべり |
| リモート荷重/変位・点質量・ばね・弾性支持・円筒支持・ベアリング荷重・ボルト予張力・ジョイント（9 種類）・ビーム接続（予張力つき）・周期対称・サブモデル | ［環境］タブ | ビーム接続と周期対称は「相手側の面」「高い側の面」を詳細のボタンで決める |
| 回転速度（遠心力）、静水圧、斜めの平面・円筒面の摩擦なし支持・対称領域 | ［環境］タブの荷重・支持 | 斜め・曲面の支持は静解析とモーダル |
| 応力の線形化（膜・曲げ・ピーク） | 結果の詳細 →「パスに沿ったグラフ…」→「応力の線形化」 | 始点と終点を板の両面に置く |
| 円筒座標系での結果（半径・周方向の変位と応力） | 結果の追加の「円筒座標系」。軸はツリーの「座標系」 | |
| 陽解法でのボディ間の接触、ボディごとの初速度 | 過渡構造（陽解法）の解析設定 | 結合は運動を厳密に結ぶ。ほかはペナルティ法（接触相手は最初の位置で固定） |
| モーダル・座屈・調和応答・熱などでの接触（結合） | 自動（接触領域があれば使う） | 節点を共有していないボディを接触でつなぐ。熱接触コンダクタンスは接触の詳細 |
| 弧長法（座屈後・飛び移り） | 解析設定 → 非線形制御 | 大変形をオンにして使う |
| 破壊力学（き裂、J 積分、応力拡大係数） | ［環境］タブの「き裂」 | 直線の前縁と半楕円の表面き裂 |
| 適応メッシュ（収束ツール）、六面体（スイープ・すべて六面体）、断面表示、アニメーション | 結果の詳細、メッシュの詳細、グラフィックスの上のバー | |
| 積層シェル（複合材） | ボディ属性の「積層」タブ | 破損指標（最大応力・Tsai-Hill・Tsai-Wu） |
| ソリッド＋シェル | ［モデル］タブでソリッドのあとに平板などを追加 | 線形の静解析とモーダル。ソリッドの表面に乗ったシェルの節点を自動で結合（回転も） |
| はり（骨組み） | ［環境］タブの「はり（骨組み）」 | 別画面。ソリッドのモデルに混ぜるのはビーム接続だけ |
| パラメータ・最適化、疲労（S-N）、式で作る結果 | ［モデル］タブの変数、結果の追加 | |

### まだできないこと（主なもの）
- ソリッド＋シェルのモデルでの接触・大変形・塑性・リモート境界条件
- 弧長法と、非線形の接触・リモート境界条件・0 以外の強制変位の組み合わせ
- 陽解法でのリモート境界条件・ジョイント・ビーム接続、大きくすべる・離れてまた当たる接触
- 周期対称で、セクタごとに違う荷重の静解析
- 六面体優勢メッシュ（スイープできない形を六面体中心で切る）
- 検証は理論解・全周モデルとの比較が中心で、Ansys 本体との直接比較はまだ行っていません

## インストール（Mac）

Finder で `start.command` を**ダブルクリック**するだけで起動します（初回は自動でセットアップ）。

ターミナルから起動する場合：

```bash
cd ~/kouchan_program/open-mechanical
./setup_mac.sh          # 初回だけ（仮想環境を作って必要なライブラリを入れます）
./run.sh                # 起動
```

手動で入れる場合：

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m openmech
```

## インストール（Windows）

環境構築は不要です。

1. GitHub の「Code → Download ZIP」でダウンロードして展開する（git があれば `git clone` でも可）
2. フォルダの中の **`start.bat`** をダブルクリック

初回だけ、Python 3.12 と必要なライブラリをこのフォルダの中（`.tools` と `.venv`）に自動で入れます（10 分ほど・インターネット接続が必要）。パソコン全体には何もインストールしないので、フォルダを消せば元どおりです。2 回目からはすぐに起動します。git で取得したフォルダなら、起動のたびに GitHub の最新版にそろえます。

- 対応: 64 ビット版 Windows 10 / 11（x64）。ARM 版 Windows は gmsh の配布がないため未対応
- 「Windows によって PC が保護されました」と出たら「詳細情報 → 実行」を押してください

## 使い方

画面構成: 上=リボン、左上=ツリー、左下=詳細、中央=グラフィックス（上に属性入力欄）、下=メッセージ

**モデル作成と属性の付け方は Femtet と同じです。**

1. **モデル作成**（［モデル］タブ）: 「新規」でまっさらな画面。「作成」の 直方体・円柱・パイプ・円錐・球・押し出し を押すと
   ダイアログが開くので、基準点と寸法を入力して［OK］。作った形状はそれぞれ別の**ボディ**（B0, B1, …）になり、
   接している面はつながって計算されます。「結合」「除去」はボディ選択モードで 対象 → Ctrl(⌘)+クリックでツール の順に選んでから。
   「穴」は選んだボディ（未選択なら全ボディ）に円柱の穴をあけます。CAD は「STEP」で取り込み。
2. **ボディ属性・材料定数**: 属性入力欄を「ボディ属性/材料定数」にして、ボディをクリック →
   「ボディ属性名」「材料名」を入力 →［設定］。材料名が材料DB（SS400、A5052 …）に無い名前なら
   ［材料定数の編集］が開きます（材料DBから読み込みも可）。［編集］でいつでも変更できます。
   ボディごとに違う材料で解析できます。
3. **境界条件**: 属性入力欄を「境界条件」にして、面をクリック → 「境界条件名」を入力 →［設定］。
   新しい名前なら［境界条件の編集］が開くので、変位（拘束）/ 荷重 / 圧力 / モーメント を設定。
   既にある名前なら、その境界条件に面が追加されます。
4. **メッシュ**: ツリー「メッシュ」で要素サイズ。ボディ属性の［編集］でボディごとのメッシュサイズも指定可
5. **⚡ 解析**（［ホーム］タブ）
6. **結果**: ツリー「解析結果」の下の項目を選ぶとコンター表示。クリックでその点の値

マウス: 左クリック=面選択 / Ctrl(⌘)+クリック=追加選択 / 左ドラッグ=回転 / Shift+ドラッグ=移動 / ホイール=拡大縮小
ツリーの印: ✓=完了　⚡=更新が必要　?=設定が足りない

**単位系**：長さ mm、力 N、応力 MPa、モーメント N·mm、加速度 mm/s²（重力 = 9806.65）

## コマンドラインでの実行（バッチ解析）

```bash
python -m openmech faces examples/cantilever.omech      # 面番号の一覧
python -m openmech run   examples/cantilever.omech --out results/
```

プロジェクトファイル（.omech）は JSON なので、パラメータを書き換えて一括で回すこともできます。

## 精度の検証（Ansys Verification Manual・NAFEMS ベンチマーク）

Ansys 自身が精度確認に使っている標準問題で検証しています。Finder で `benchmark.command` を
ダブルクリックすると、Mac 上で全問題を再計算して `logs/benchmark.txt` に保存します。

「比」= 本ソフトの値 ÷ 目標値（1.000 が完全一致）。要素はすべて 2次四面体（Ansys の SOLID187 相当）。

| 問題 | 評価量 | 目標値 | 本ソフト（標準メッシュ） | 本ソフト（細かいメッシュ） | Ansys SOLID187 |
|---|---|---|---|---|---|
| **Ansys VMC1** 周辺固定板 | 中央たわみ | -0.0172 in | 0.973 | 0.983 | 0.984 |
| 〃 | 固定辺の応力 SX | -32.12 ksi | 0.984 | 0.974 | 0.966 |
| 〃 | 中央の応力 SX | 14.47 ksi | 0.998 | 0.999 | 1.000 |
| **NAFEMS LE1** 楕円膜 | 点D σyy | 92.7 MPa | 0.981 | 0.994 | – |
| **NAFEMS LE10** 厚板の圧力 | 点D σyy | -5.38 MPa | 0.976 | 0.984 | – |
| 厚肉円筒の内圧（ラメの解） | 内面の円周応力 | 166.7 MPa | 1.002 | 1.000 | – |
| 〃 | 内面の変位 | 0.0953 mm | 0.998 | 1.000 | – |
| 片持ち梁 | 先端たわみ | 1.008 mm | 0.983 | 0.990 | – |
| 穴あき板の引張（gmsh 自由メッシュ） | 穴縁の応力集中（板厚平均） | 62.66 MPa | 1.024 | 1.020 | – |

- Ansys VMC1 は Ansys が公開している同じ問題・同程度のメッシュ（10×10×2）での SOLID187 の結果と比べています。
  本ソフトは **3項目とも Ansys との差が 1.5% 以内** です。
- NAFEMS LE10 は、他の商用ソルバー（Altair OptiStruct）の 2次四面体でも目標値に対して 0.94〜1.07 の範囲です。
- 穴あき板の目標値は Peterson の応力集中係数の近似式（平面応力）で、式自体に 1〜2% 程度の誤差があります。

`python -m pytest -q` で、標準メッシュの結果が目標値の ±3% 以内であることを自動テストしています。

## 計算速度について

ソルバーは自動で最速のものを選びます。大きなモデル（数十万自由度〜）を速く解きたい場合：

- `pip install pyamg` … AMG 反復法（Apple Silicon でも動作・requirements に含む）
- `brew install suite-sparse && pip install scikit-sparse` … CHOLMOD 直接法（高速）
- Intel Mac / Windows なら `pip install pypardiso`

## 構成

```
openmech/
  mesh.py        四面体メッシュ、境界面の抽出と面の自動分割
  solver.py      剛性マトリクス組立・境界条件・求解・応力計算
  geometry.py    gmsh による形状作成・CAD 読込・メッシュ生成
  materials.py   材料ライブラリ
  project.py     プロジェクトの保存/読込（.omech）
  export.py      VTU / CSV / HTML レポート
  cli.py         コマンドライン
  gui/           デスクトップアプリ（PySide6 + PyVista）
tests/           理論解との比較テスト
```

## 注意

本ソフトの結果は参考値です。重要な設計判断では、収束確認（メッシュを細かくして結果が変わらないこと）や
手計算・実験・商用ソフトとの比較で妥当性を確認してください。
